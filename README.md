# Responsive Landing Page

A responsive product/service landing page built with HTML and CSS. The page includes a hero section, feature cards, CTA buttons, and modern hover effects for a polished look.

## Features
- Fully responsive layout for desktop, tablet, and mobile
- Hero section with strong headline and call-to-action buttons
- Product/service feature cards
- Smooth hover animations
- Semantic HTML and meta tags
- Clean, modern dark theme

## Files
- `landing_page.html` — main landing page markup and styles

## Preview locally
1. Open the file directly in the browser, or
2. Use a local preview tool such as Live Server in VS Code
